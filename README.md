# Retro Fallen Tale

ブラウザで遊べるレトロRPGデモです。

## ファイル構成

```text
index.html
game.js
style.css
assets/
  hero.png
  hero-lying.png
  flowey.png
  ruins.png
  flowers.png
```

## 操作

- 方向キー: 移動・選択
- Enter / Z: 決定
- X / Escape: 戻る

`index.html` をブラウザで開くと起動します。音楽はSpotify埋め込みを使用しているため、最初のキー入力またはタップ後に再生されます。
