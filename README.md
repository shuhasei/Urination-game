# Retro Fallen Tale

UNDERTALE 10周年をモチーフにした、ブラウザで遊べるステージ制レトロバトルゲームです。

## ゲーム進行

1. タイトル画面から最初の道へ進む
2. 道の右端から選択中のステージへ挑戦
3. クリア後は準備画面で「REPLAY」か「NEXT」を選択
4. 選択後は一度道へ戻り、右端へ進むと戦闘開始
5. 同じステージを再戦しても勝利ごとにLVが上昇
6. 各敵はLV1からLV20まで20種類の攻撃パターンを持つ
7. 最終ステージでは青いハートと骨攻撃を使うサンズ戦が開始

## 成長と戦闘表示

- LV1の最大HPは20
- 勝利ごとにLVが1上昇
- LV20の最大HPは80
- 敵の現在HPと最大HPをゲージ表示
- LVに応じて弾の方向、速度、間隔、同時発射数、重力挙動が変化
- 攻撃成功時にダメージ数値と斬撃を表示
- ステージクリア時にHP、ケーキ、復活アイテムを補充

## 操作

- 方向キー: 移動・選択・攻撃回避
- Enter / Z: 決定・攻撃
- X / Escape: 戻る

戦闘曲はSpotifyの公式埋め込みを使用します。通常戦はToby Foxの楽曲からランダム選曲され、最終戦では「MEGALOVANIA」がループ再生されます。ブラウザの自動再生制限により、最初のキー入力後に再生が始まります。
