# Retro Fallen Tale

UNDERTALE 10周年をモチーフにした、ブラウザで遊べるステージ制レトロバトルゲームです。

## ゲーム進行

1. タイトル画面から10室が連結された地下通路へ進む
2. 部屋の左右端から隣室へ移動でき、前の部屋にも自由に戻れる
3. 各部屋上部の入口へ入ると、部屋番号に対応するステージが開始
4. クリア後は「REPLAY」か「RETURN」を選択
5. 「RETURN」では同じ部屋へ戻り、その後の移動先はプレイヤーが決める
6. 同じステージを再戦しても勝利ごとにLVが上昇
7. 各敵はLVごとに3種類、LV1からLV20まで合計60種類の攻撃パターンを持つ
8. 最終ステージでは青いハートと骨攻撃を使うサンズ戦が開始

## 成長と戦闘表示

- LV1の最大HPは20
- 勝利ごとにLVが1上昇
- LV20の最大HPは80
- 敵の現在HPと最大HPをゲージ表示
- LVに加えてステージ番号でも弾速、発射間隔、同時発射数、波幅、ダメージが段階的に上昇
- 後半ステージほど内部の回避経路が狭くなるが、全攻撃に回避手段を維持
- 横掃射、雨、床上昇、挟み撃ち、照準弾、波状弾、壁、四隅、回転弾、扇状弾など20系統を収録
- 各ステージに固有の敵シルエットを用意
- 敵ターンの前に、敵ごとの戦闘セリフをタイプライター表示
- セリフの各文字に敵ごとに音程の異なる発声音を再生
- 全攻撃に回避可能な経路を内部的に確保し、正解位置は画面に表示しない
- 骨、通常弾、ブラスターの全パターンに回避手段を用意
- 最終戦のサンズは、通常・瞬き・手上げ・手下げ・横指し・居眠り・最終回避・負傷座り・負傷立ち・負傷歩行の各ポーズを動画資料から再構築
- 通常の瞬きと負傷歩行はGIFでアニメーションし、その他のサンズ画像と4コマンド画像もData URIとしてgame.jsへ直接埋め込み
- 生成的な描き足しで輪郭を変えず、動画フレーム由来のピクセルを拡大・透過整理・減色して原画との一致を優先
- 画像生成で作成した高解像度のサンズと4コマンド画像もData URIとして埋め込み、動画由来の画像を読み込めない場合の予備画像として使用
- 埋め込み画像を読み込めない場合は、矩形ピクセル描画へ自動フォールバック
- サンズの片目は23段階中、最後のスペシャル攻撃でのみ発光
- サンズ戦は青いハート、骨の壁、床の骨、横流し、重力ジャンプ、頭蓋型ブラスターを固定順で使用
- 最終戦の全攻撃シーケンスが終わるまでサンズが攻撃を回避し、最後の一撃だけ命中
- 最終骨トンネルと壁叩きつけには、ハートの当たり判定を含めた回避可能な余白を確保
- 移動床攻撃3種と最終攻撃は自動回避探索と実リプレイでノーダメージ経路を確認
- 最終戦のあらすじとセリフは独自内容に再構成
- ブラスターは照準予告後に白と水色の縦横レーザーを発射
- LV6から通常敵も攻撃を回避し、LV上昇に応じて回避率が増加
- 通常敵は連続回避を行わず、回避時は横移動とMISSを表示
- 攻撃成功時にダメージ数値と斬撃を表示
- ステージクリア時にHP、ケーキ、復活アイテムを補充

## 操作

- 方向キー / WASD: 移動・選択・攻撃回避
- 青いハート: Z / Space / Enter / 画面のOKでジャンプ（短く押すと低く、長く押すと高く跳ぶ）
- ジャンプ入力には先行受付とコヨーテタイムがあり、押したまま着地しても次のジャンプを受け付ける
- 狭い枠では飛びすぎない高さへ自動調整し、短押しと長押しで高さを変えられる
- Enter / Z: 決定・攻撃
- 最終場面: ハートを枠の左下へ動かして左へ引き、次に下へ引く。枠が「たたかう」に重なったら、ハートを黄色表示になる位置へ動かして決定
- X / Escape: 戻る


## 検証結果

- Chromiumの決定論的テストで、サンズ戦の全23攻撃が終了状態まで進むことを確認
- 最終攻撃（攻撃22）は20fps・1002入力ステップの自動経路を再生し、被弾0・HP減少0で最終枠へ到達
- 壁叩きつけ攻撃（攻撃16・17・21）は無操作でも被弾0。着地点の安全幅は上下左右とも28px
- 最終骨トンネルは最小開口23px、隣接する開口中心の最大変化2pxを確保
- 最終枠は動画から換算した開始位置 `(124.5, 85, 74, 55.5)` から左、下の順に移動し、「たたかう」への重なり、回避、最終命中、会話、歩行、ステージクリアまで通し確認
- 赤・青ハートは同じ7×7ピクセル形状を使用

戦闘曲はSpotifyの公式埋め込みを使用します。通常戦はToby Foxの楽曲からランダム選曲され、最終戦では「MEGALOVANIA」がループ再生されます。ブラウザの自動再生制限により、最初のキー入力後に再生が始まります。
